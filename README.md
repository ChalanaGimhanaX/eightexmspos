# Enightx POS

Planning baseline for a general-purpose Windows desktop POS for Sri Lankan shops.

Status: specification and proposed design only; no application has been implemented.

- [First-release specification](docs/first-release-specification.md)
- [Technical design](docs/technical-design.md)
- [Delivery plan and acceptance checks](docs/delivery-plan.md)

The specification distinguishes agreed requirements from proposed defaults and unresolved commercial decisions. Unlimited commercial usage does not imply unlimited tested technical capacity.
